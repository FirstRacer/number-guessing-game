# number-guessing-game
🎯 Number Guessing Game

Guess smart. Beat the clock. Become the champion! 🏆

Welcome to an interactive number guessing challenge! Test your logic and luck by finding the secret number using helpful hints and limited attempts.

✨ Features

- 🎮 Three difficulty modes: Easy, Medium, and Hard
- 💡 Smart hints: Too High, Too Low, and Very Close
- ⏱️ Timer that starts with your first guess
- 🏆 Score tracking and best-score saving
- 🔢 No repeated secret numbers until the deck resets
- 🎉 Celebration effects when you win
- 🌙 Light and dark themes
- 📱 Mobile-friendly design

🕹️ How to Play

1. Select your preferred difficulty.
2. Enter your guess and submit it.
3. Follow the hints to get closer to the secret number.
4. Find the correct number before your attempts run out.
5. Improve your score and beat your personal best!

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

🚀 Getting Started

1. Clone or download this repository.
2. Open the game's HTML file in your browser.
3. Choose a difficulty and start guessing!

🎯 Goal

Use logic, follow the hints, and guess the secret number with as few mistakes as possible.
